# 가상 투자 계획 📈

연금·ISA·증권 계좌를 한눈에 관리하고 장기 자산 성장을 시뮬레이션하는 개인 투자 계획 **휴대폰 앱**(PWA)입니다.
엑셀로 관리하던 투자 계획을 휴대폰에서 편하게 설정하고 계획할 수 있도록 만들었습니다.

## 주요 기능

- **대시보드** — 선택 연도의 총 자산, 은퇴/최종 예상 금액, 계좌별 자산 구성(도넛), 성장 곡선 차트
- **계좌 관리** — 연금A/B, ISA, 증권(GOOG·TSLA·SpaceX 등) 계좌를 유형별로 관리, 탭하여 수정
- **계좌 편집** — 시작 평가액·월 납입액·연 성장률·색상 설정, **연도별 변경 계획**(특정 연도부터 월납입 변경, 일시 입금/출금)
- **연도별 계획** — 계좌 합산 시뮬레이션 표(순납입·성장·평가액)와 자산 성장 그래프
- **설정** — 시뮬레이션 기간·은퇴 연도·출생 연도, 데이터 백업/복원(JSON), 초기화

## 특징

- 📱 **홈 화면에 추가**하면 네이티브 앱처럼 전체화면·오프라인 동작 (PWA)
- 💾 모든 데이터는 **휴대폰에만 저장**(localStorage) — 서버 전송 없음
- 🧮 엑셀과 동일한 복리 모델: `평가액 = 이전 × (1+성장률) + 연납입 + 일시금`
- 🎨 순수 바닐라 JS/CSS — 빌드·의존성 없음

## 사용 방법

1. 웹 서버로 이 폴더를 열거나 배포합니다. (예: `python3 -m http.server`)
2. 휴대폰 브라우저(Safari/Chrome)로 접속합니다.
3. **공유 → 홈 화면에 추가**를 누르면 앱으로 설치됩니다.

초기 데이터에는 제공해 주신 ISA 투자 계획(연금A/B·ISA·증권)이 예시로 들어 있으며,
각 계좌를 탭해 본인의 계획에 맞게 자유롭게 수정할 수 있습니다.

## 구조

```
index.html            앱 셸 + 하단 네비게이션
css/style.css         모바일 우선 다크 테마
js/utils.js           숫자 포맷(억/만)·SVG 차트
js/store.js           데이터 저장 + 시뮬레이션 엔진
js/app.js             화면 렌더링·라우팅·계좌 편집
manifest.webmanifest  PWA 매니페스트
sw.js                 서비스 워커(오프라인 캐시)
icons/                앱 아이콘
```
